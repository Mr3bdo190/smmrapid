# RapidSMM 2.0 — Client Pages Rebuild

The authenticated client area was refreshed onto one design system rather than changing only the landing page.

## Rebuilt client experience
- Dashboard: new visual shell, balance-first hierarchy, modern cards and responsive behavior.
- New Order: Category → Section → Service flow with compact selectors and service details.
- Orders / Mass Orders: consistent tables, filters, status treatment and responsive overflow.
- Add Funds / Transactions: wallet-focused USD presentation and payment cards.
- Services: unified catalog/card styling.
- Affiliates / Earn: growth-focused cards and referral presentation.
- Tickets / Ticket View: consistent support workspace and conversation styling.
- API: unified documentation/key-management presentation.
- Profile: account settings in the same design language.
- Lottery / Mystery Boxes / Game / Shortlinks: same card, action, status and spacing system.

## Application shell
- Dark RapidSMM client sidebar with grouped navigation.
- New topbar and balance/profile treatment.
- Mobile bottom navigation for the primary five destinations.
- Unified controls, tables, inputs, buttons, shadows, radii and spacing.
- Authenticated routes continue to use the existing backend/API logic; the redesign is intentionally presentation-layer focused so existing business flows are preserved.
