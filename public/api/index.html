RapidSMM API for Resellers

Connect your own storefront, bot or application to RapidSMM with a reseller-friendly API.

What you can automate

  • Read the current account balance.
  • Load active services with rate and quantity limits.
  • Create new orders programmatically.
  • Check order status and progress.

Typical integration flow

Authenticate with your API key, request the service catalog, calculate the customer charge on your side, create the order, store the returned order ID and poll status when your application needs an update.

Keep your API key private

Never expose a reseller API key in browser JavaScript or public source code. Send requests from your server-side application and rotate the key if you suspect it has been exposed.

Service pricing

RapidSMM selling rates are controlled by the service catalog. Provider sync can update provider cost, limits and metadata while the configured provider margin determines the customer-facing rate.

Need the live API key?

Create an account, open the dashboard API section and generate your key. For integration help, contact support.
